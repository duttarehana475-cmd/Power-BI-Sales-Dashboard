# Skincare Product Analysis Dashboard

This project analyzes skincare products using Power BI.

## Project Overview

The dashboard provides insights into skincare products based on category, stock quantity, cost price, MRP, and product-level analysis.

## Key Analysis

- Products by Category
- Stock Quantity by Category
- Average MRP vs Cost Price
- Top Products by Stock Quantity
- Product-wise Price Analysis
- Gross Margin Analysis

## Tools Used

- Power BI
- CSV Dataset

## Files

- Products.csv – Dataset used for the analysis
- Skincare Dashboard image – Dashboard visualization

## Objective

The objective of this project is to understand skincare product inventory, pricing, and category-level patterns through data visualization.
